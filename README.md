# Edinburgh Nerf War Society

A simple responsive coming-soon page using plain HTML, CSS, and the supplied `logo_v3.svg`. No dependencies or build step.

## Preview locally

Run `python3 -m http.server 3000` in this directory, then visit http://localhost:3000.

## Deploy to Vercel

Push this directory to a GitHub repository and import it into Vercel. Select **Other** as the framework preset, leave the build command unset, and use `.` as the output directory.

The landing page is in `index.html`, with styling in `styles.css`. To use another supplied logo, change the image and favicon paths in `index.html` (and the image width and height to match its SVG).
